# toolbox-utils

Xeno executor script. Paste this into the executor and run it:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/AtomicStar1/toolbox-utils/main/install.lua"))()
```

This downloads the loader + game scripts into your Xeno workspace and opens the picker UI. Re-run it any time to update to the latest version.

To have the picker come back automatically after a rejoin, copy the contents of `RockFruit_Autoexec.lua` into `%LOCALAPPDATA%\Xeno\autoexec\` as its own `.lua` file, once.
